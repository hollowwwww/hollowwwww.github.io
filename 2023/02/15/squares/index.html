走方格的方案数

发表于2023-02-15|递归

题目描述

请计算 n∗mn*mn∗m 的棋盘格子（nnn 为横向的格子数，mmm 为竖向的格子数）沿着各自边缘线从左上角走到右下角，总共有多少种走法，要求不能走回头路，即：只能往右和往下走，不能往左和往上走。

递归思想

从 (m,n)—>(0,0)(m, n)—>(0, 0)(m,n)—>(0,0) 就只有两种走法：往右走一步：f(m,n−1)—>(0,0)f(m, n - 1)—>(0, 0)f(m,n−1)—>(0,0) 或 往下走一步：f(m−1,n)—>(0,0)f(m - 1, n)—>(0, 0)f(m−1,n)—>(0,0)递归通式：f(m,n)=f(m,n−1)+f(m−1,n)f(m, n) = f(m, n - 1) + f(m - 1, n)f(m,n)=f(m,n−1)+f(m−1,n)当走到边界，即 f(0,x)f(0,x)f(0,x) 或 f(x,0)f(x,0)f(x,0) 都只能走一条直线了递归终止条件：n=0∣∣m=0n = 0 || m = 0n=0∣∣m=0
