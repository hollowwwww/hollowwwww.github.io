Hexo添加天气时钟

发表于2026-03-23|操作手册
|总字数:661|阅读时长:2分钟|浏览量:

本次使用的插件来自hexo-butterfly-clock-veeink，天气服务由和风天气提供，以下是原文档内容

这是基于hoochanlon/hexo-butterfly-clock-remake 项目修改而来的版本，新增高德地图 IP 定位支持 适用于 Hexo + Butterfly 主题，提供实时天气、时间、城市自动定位等功能。

功能特性

  • 以和风天气API为执行基础。

  • 通过IP定位API拿到城市位置，通过城市位置拿到和风天气location id

  • 再通过location id获取到天气

  • 增加高德地图api方案

和风天气账号设置

qweather_key

进入和风天气开发者服务，完成账号注册后进入到控制台，点击项目管理 》创建项目 》创建凭据，凭据名称自取，身份认证方式选择API KEY，启用API选择指定API，把免费的几个都勾上（GeoAPI一定要勾选，否则获取不到所在地location id）

完成后保存，qweather_key = API KEY

qweather_api_host

进入和风天气控制台设置菜单

qweather_api_host = https://API Host

这里要注意 一定要加上https前缀，否则API HOST会被当成你站点下的相对路径，运行时会自动基于当前页面的源去解析，url会自动拼接上你的域名

高德地图key设置

进入高德开放平台，进入控制台 》 管理Key

点击添加Key，选择Web服务

完成后在页面复制Key即可
