Hexo访问加速(CDN)

发表于2026-08-02|操作手册博客加速
|总字数:1.3k|阅读时长:3分钟

前言

笔者之前不是瞎搞了个旅行足迹地图吗，还乐此不疲的加上了图库链接跳转功能(详情可见之前文章:Hexo添加旅行足迹)。由于笔者把以前去过的大大小小的地方全都一股脑添加了进去，这下好了，图片资源直接爆满，哪怕已经使用工具将全站的图片统统压缩过一边了依旧庞大，再加上笔者的站点资源全放在Github Pages上，让本就不堪的访问速度直接奔溃了，老半天加载不出来，手机访问更是白屏，无奈整起CDN，特此记录

常见加速类型

CDN（Content Delivery Network，内容分发网络） 加速按类型可分为：

  1. 静态资源加速（基础 CDN）
    图片、JS、CSS、静态 HTML、压缩包、安装包等可缓存资源；节点缓存，命中直接返回，极少回源。适合官网、图片、下载站。

  2. 全站 / 动态加速（DCDN/ECDN）
    动态接口、PHP/JSP、登录、购物车、API 这类无法长期缓存的内容；靠智能路由、TCP 优化、协议优化、就近回源、路由优选，而不是靠缓存。适合电商、后台、小程序接口。

  3. 点播加速（VOD）
    MP4、HLS 等点播视频，支持分片缓存、预加载、视频转码、防盗链。

  4. 直播加速
    RTMP/HTTP-FLV/HLS 直播流分发，低延迟推流、拉流加速。

  5. 大文件下载加速
    分片回源、断点续传、Range 分片缓存，适合安装包、镜像。

  6. 海外 / 全球加速
    跨境链路优化，解决国内访问海外、海外访问国内延迟、跨运营商丢包

个人博客由于大多是静态资源，所以采用 静态资源加速 或 整站加速 均可

笔者采用的后者 整站加速 方案

主流CDN选型

国内云厂商

  1. 火山引擎 CDN
    强项：直播、点播、短视频、大流量音视频，抖音同款底层；国内节点多，带宽储备足；DCDN 动态加速成熟适合：短视频、直播、APP 点播、大流量媒体业务短板：纯静态小流量性价比一般

  2. 腾讯云 CDN
    强项：直播、小程序、游戏、南方运营商质量好；和微信生态适配好适合：小程序、小游戏、直播带货、社交类 APP

  3. 阿里云 CDN
    强项：电商、全站动态、大促弹性、生态最全；DCDN 成熟，WAF / 安全配套强适合：电商、交易类网站、混合动静业务、阿里云生态用户

  4. 华为云 CDN
    强项：信创、政企、国产化、国内下沉节点；云原生、边缘云配套适合：政企、政务、信创项目

专业独立CDN厂商

  1. 网宿科技：老牌专业 CDN，政企、金融、大型直播、大带宽项目；定制化、合规、专线能力强；适合高稳定、高 SLA 企业项目，价格偏商务合同价

  2. 白山云：边缘计算、API 动态加速、安全一体化

中小性价比（自助、轻量、静态 / 中小流量）

  1. 七牛云：静态、对象存储 + CDN 一体化，图片处理强，中小站点友好

  2. 又拍云：自助配置简单，图片 / 小文件加速，中小网站、开发者友好又拍云

海外 CDN（外贸、海外用户，无国内备案加速资质）

  1. Cloudflare：免费版很香，安全强，边缘函数；国内访问延迟波动大，不适合国内用户

  2. BunnyCDN：海外性价比高，简单，适合外贸、海外站点

  3. Fastly：可编程边缘、超低缓存刷新，适合开发者、API 业务

笔者采用 腾讯云 CDN 方案，后文内容均在此基础上操作

以上内容仅为罗列展示，不构成推荐建议，请自行甄别

CDN接入

添加域名

登录腾讯云CDN控制台，在左侧导航栏中，单击域名管理进入域名管理页面，单击添加域名

域名配置

根据自己的网站信息，填写配置表单

源站配置

源站即为存储网站资源的服务器，当用户请求的资源在 CDN 节点无缓存，节点会读取域名配置的源站信息，回源拉取资源并缓存在节点。因此，源站信息务必填写准确，保证 CDN 能正常回源取到对应的资源。

笔者的站点托管在github上，因此源站直接填写对应仓库名即可，如 xxxxxx.github.io

配置CNAME

添加完成加速域名后，CDN会分配一个专属的CNAME地址。如果域名就是在腾讯云购买的，那这一步就可以一键配置了，否则就需要像笔者一样去购买域名的服务商处完成CNAME配置

如果你的域名之前已经解析过Github Pages，那么这里应该已经有一条主机记录为 @ ，记录类型为 A 的记录，此时将这条 A 记录改为 CNAME ，记录值 也做相应更改即可

验证CNAME是否生效

单击 验证CNAME状态,查看当前域名CNAME是否生效

加速效果实测

做完上述步骤再次访问网站，速度直接杠杠滴！
