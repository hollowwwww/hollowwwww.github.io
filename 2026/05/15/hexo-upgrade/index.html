Hexo版本升级记录

发表于2026-05-15|操作手册
|总字数:1.6k|阅读时长:8分钟

闲来无事给自己找点事做，把Hexo以及在用的butterfly主题都升级到最新了，特此记录

以下指令均在hexo目录下操作

定位到hexo博客目录，运行 hexo -v 查看当前版本

全局升级hexo-cli，运行npm i hexo-cli -g

出现报错，分析错误码说明当前用户没有权限在D:\nodejs\node_modules 目录下创建 hexo-cli 文件夹，本质是 Windows 目录权限问题，我的解决方法很简单，右键 D:\nodejs 文件夹 → 属性 → 安全 → 编辑，选中当前用户，勾选“完全控制”后重试即可

安装 npm-check，运行npm install -g npm-check

检查系统插件是否需要升级，运行npm-check

这里可以看到所有可升级依赖项都已经列出

安装npm-upgrade，运行npm install -g npm-upgrade

更新 package.json，运行npm-upgrade

一直回车回车就行，最后一项需要输入Y或y，到这一步package.json中的所有依赖项都已升级完成了，但是hexo的版本还是老版本

更新全局插件，运行npm update -g

更新系统插件，运行npm update --save

再次查看版本，确认是否升级成功

到这hexo就已经升级成功了

升级主题，运行npm update hexo-theme-butterfly --save

只需几分钟即可大功告成！
